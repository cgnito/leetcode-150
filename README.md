# LeetCode 150

My solutions and notes for the [LeetCode 150](https://leetcode.com/studyplan/top-interview-150/) study plan.

I'm using this repository to practice data structures and algorithms, but more importantly, to **understand the problems rather than just collect solutions**.

For each problem, I write the solution myself and document the reasoning behind it — the intuition, approach, complexity, and anything I learned while solving it.

## Structure

Each problem has its own directory:

```text
001-problem-name/
├── main.py
└── README.md
```

* `main.py` — my implementation of the solution.
* `README.md` — my notes on the problem, including:

  * intuition
  * approach
  * why the solution works
  * time and space complexity
  * lessons or things I found interesting

## Goal

The goal isn't to rush through all 150 problems.

I want to build a strong mental model for common data structures and algorithms and become better at recognizing patterns when solving new problems.

> Understand the problem. Build the intuition. Then write the code.
